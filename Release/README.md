# MalumMenu v3.2.0 - Complete Release Package

## 🚀 Quick Install

1. **Extract ALL files** from `MalumMenu-v3.2.0-Steam-Itch.zip` into your Among Us folder
2. **Launch Among Us**
3. **Press DELETE** in-game to open MalumMenu
4. **Configure AI Mode** in the AI tab

## 📦 What's Included

- **MalumMenu.dll** (v3.2.0 with AI Mode)
- **BepInEx** (mod loader framework)
- **Doorstop** (injector)
- **.NET Runtime** (required for IL2CPP)
- **Steam App ID** (for Steam launches)
- **MalumMenu Injector** (one-click installer)

- **Groq-Powered Analysis** - Real-time game state analysis


### Step 2: Copy to Game Folder
Copy ALL extracted files into your Among Us game directory.

### Step 3: First Launch
Launch Among Us - BepInEx will install automatically on first run.

## 🔧 Using the Included Injector

If you prefer a GUI installer:

1. Run `MalumMenuInjector.exe`
2. Click "Browse" to select your Among Us folder
3. Click "Download & Install" to get the latest release
4. Launch Among Us and press DELETE to open the menu

The injector handles everything automatically - no manual file management needed!
